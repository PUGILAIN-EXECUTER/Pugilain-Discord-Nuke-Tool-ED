## 📋 Descrizione

**Pugilain-Discord-Nuke-Tool-ED.** è un potente tool di stress testing progettato specificamente per server Discord. Questo software permette ai proprietari e agli amministratori di server di verificare la robustezza delle proprie difese contro potenziali attacchi come raid, nuke o spam.

Il tool simula scenari di attacco realistici per aiutarti a identificare vulnerabilità nel tuo server **PRIMA** che lo facciano gli attaccanti reali.

---

## 🔥 Funzionalità Principali

- 🛡️ **Test Anti-Raid** - Simula attacchi raid per verificare la resistenza del tuo server
- 💣 **Test Anti-Nuke** - Verifica se il tuo server è protetto contro tentativi di nuking
- ⚡ **Stress Test** - Misura le performance del server sotto carico elevato
- 🔍 **Analisi Vulnerabilità** - Identifica punti deboli nella configurazione
- 📊 **Report Dettagliato** - Ricevi un report completo dopo ogni test
- 🖥️ **Interfaccia Semplice** - CLI intuitiva e facile da usare
- 🚀 **Esecuzione Rapida** - Test veloci ed efficienti
